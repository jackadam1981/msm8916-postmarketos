# OpenStick-Like Devices

This folder is for MSM8916 USB dongles and pocket-router boards related to the OpenStick and UFI ecosystem.

The upstream lk2nd source already contains several modem-stick candidates. Treat these as leads:

- UFI_001B/C, UFI003_MB_V02, MF601
- UFI-001C / UFI-001B
- UZ801 v3.0
- JZ0145 v33
- UF896

Do not assume one device tree covers every device in this family. Add or update a specific metadata file only after extracting or otherwise verifying its Qualcomm IDs and hardware notes.
